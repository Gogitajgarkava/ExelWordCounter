# WordCounter — Excel ტექსტის ანალიზატორი

Excel / CSV ფაილიდან ან უბრალოდ ჩასმული ტექსტიდან ითვლის სიტყვებს, უნიკალურ სიტყვებს,
სიმბოლოებს, შევსებულ უჯრებს და სიტყვების სიხშირეს. ყველაფერი მუშავდება **მხოლოდ ბრაუზერში** —
ფაილი სერვერზე არ იტვირთება.

## შესაძლებლობები

- **ორი წყარო:** Excel ფაილი (`.xlsx`, `.xls`, `.xlsm`) ან CSV, ან პირდაპირ ჩასმული ტექსტი
- **Sheet-ების არჩევა:** მთელი ფაილი ან კონკრეტული Sheet
- **ჭკვიანი ფილტრები:**
  - მხოლოდ ციფრების იგნორირება (`125`, `99.9`, `₾ 1 250`)
  - პუნქტუაციისა და სასვენი ნიშნების ამოღება (Unicode-მხარდაჭერით)
  - ბმულებისა და Email-ების გამოტოვება
  - რეგისტრის იგნორირება (`Word` = `word`)
  - სათაურების / პირველი ხაზის გამოტოვება
  - მინიმალური სიტყვის სიგრძე (1–10 ასო)
- **ცოცხალი სტატისტიკა:** სიტყვები, უნიკალური სიტყვები, სიმბოლოები ჰარებით/გარეშე, უჯრები, გამოტოვებული ელემენტები
- **სიხშირის ცხრილი:** ძებნა, ანბანური/სიხშირული სორტირება, 100-100 სტრიქონის დამატება
- **მონაცემების გადახედვა:** პირველი 50 სტრიქონი Excel-ის სვეტების აღნიშვნებით
- **CSV ექსპორტი:** UTF-8 BOM-ით — ქართული სწორად იხსნება Excel-ში
- **სადემონსტრაციო ტექსტი** ერთი დაჭერით
- სრულად რესპონსიული, კლავიატურით მართვადი და ლოკალური ფონტებით (გარე CDN-ის გარეშე)

## ლოკალურად გაშვება

ES modules-ის გამო გვერდი საჭიროებს HTTP სერვერს (უბრალოდ `index.html`-ის გახსნა `file://`-ით არ იმუშავებს).

```bash
npm install          # საჭიროა მხოლოდ CSS-ის აწყობისთვის
npm run serve        # ან: npx serve .
```

შემდეგ გახსენით ტერმინალში მითითებული მისამართი (ჩვეულებრივ `http://localhost:3000`).

### CSS-ის შეცვლა

`css/app.css` უკვე აწყობილია და ჩაკომიტებულია, ამიტომ დეპლოის build არ სჭირდება.
თუ Tailwind კლასებს ან `src/styles.css`-ს შეცვლით:

```bash
npm run build        # ან: npm run dev (watch რეჟიმი)
```

### ტესტები

```bash
npm test
```

## Vercel-ზე განთავსება

**ვარიანტი 1 — CLI:**

```bash
npx vercel
```

**ვარიანტი 2 — Dashboard:**

1. ატვირთეთ პროექტი GitHub-ზე.
2. Vercel-ში აირჩიეთ **Add New → Project** და დააკავშირეთ რეპოზიტორი.
3. Framework Preset: **Other**. Build Command და Output Directory შეიძლება ცარიელი დარჩეს —
   პროექტი სტატიკურია (`.vercelignore` გამორიცხავს `src/`, `tests/`, `node_modules/`-ს და ა.შ.).
4. Deploy.

`css/app.css` ჩაკომიტებულია, ამიტომ Vercel-ს დამატებითი build არ სჭირდება.
`vercel.json` ამატებს CSP-ს, უსაფრთხოების header-ებსა და ქეშირებას.

## ფილტრების ლოგიკა

- **სიმბოლოები** ითვლება URL/Email-ების ამოღების შემდეგ; პუნქტუაცია სიმბოლოებად რჩება.
- **ციფრებით მხოლოდ** სავსე უჯრა მთლიანად გამოიტოვება (არც სიტყვებში, არც სიმბოლოებში).
- **სათაურის გამოტოვება** მოქმედებს თითოეული არჩეული Sheet-ის პირველ რიგზე; ტექსტის რეჟიმში — პირველ ხაზზე.
- **მინიმალური სიგრძე** ითვლის Unicode სიმბოლოებს და არა ბაიტებს.
- **სიხშირის ცხრილი** აჩვენებს პირველ 100 სიტყვას; „მეტის ჩვენება“ ზრდის ლიმიტს 100-ით.
  CSV ექსპორტი ყოველთვის შეიცავს **ყველა** ნაპოვნ სიტყვას.

## შეზღუდვები

- მაქსიმალური ფაილის ზომა: **25 MB**.
- დაშიფრული (პაროლიანი) Excel ფაილები არ იკითხება — გამოჩნდება შეტყობინება.
- დიდი ფაილის დამუშავება მთავარ ნაკადში ხდება; 25 MB-მდე ფაილზე პროცესი წამებში სრულდება.

## ტექნოლოგიები

- HTML5 + ES modules (დამოკიდებულების გარეშე)
- Tailwind CSS 3 (build-time, runtime CDN არ არის)
- [SheetJS](https://sheetjs.com/) — Excel/CSV პარსინგი
- Inter + Noto Sans Georgian — ლოკალური woff2 ფონტები
